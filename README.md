# 風のゆくえ — THE VERDANT WILDS / WILDFRONT

## 2026-09-19 更新：景観拡張と動作優先
- 初期設定は **Performance / 動作優先**。描画は最大160万画素・CSSピクセル比1、負荷が続く場合は倍率を0.65まで段階的に下げ、余裕が続く場合だけ戻します。固定FPSを保証する機能ではありません。
- 草の初期描画は30,000本（高画質では98,000本）。移動時の再配置は1フレーム1,500本ずつ行い、大きな一括更新を避けます。
- 地形は動作優先で115,200三角形、高画質で460,800三角形。動作優先では既存の広葉樹の樹冠も簡略化します。
- 動作優先の影は1024px・最大毎秒10回更新。雨は1,200本、追加の葉は2,000個、小石は950個。タブが非表示なら描画とゲーム更新を停止し、メニュー中は描画を毎秒10回までに抑えます。
- 針葉樹520本、低木2,100株、シダ2,200株、野花6,200株、キノコ900個、岩1,400個、倒木120本を追加。小屋7・野営地6・遺跡5・風車1も配置しました。
- 追加景観は39,206個のインスタンス部品にまとめ、距離で描画を省略。初期の小物密度は40%、建物は維持します。追加物は景観用で、建物内部や厳密な剛体衝突はありません。
- 空と視線に応じた水面表現、Ultra / Extreme / UHD（長辺3840pxを目標、画素数・GPU上限による制限あり）も手動で選択できます。
- 既存ブランチのスタミナ・コンボ・溜め攻撃・方向回避・風の導き・アイコン中心のHUDを維持しています。
- 設定はセッション内のみ。探索・戦闘のセーブとは独立しており、既存セーブを引き続き使用します。

## プロジェクト概要・目標
スマホ横画面向けの3Dオープンワールド探索・アクションゲーム。草原の旅に、運転できる車、飛行できる飛行機、ゴブリン、人間の襲撃集団「クリーチャーズ」、天候イベントとボス戦を追加しました。

静的HTML / CSS / JavaScriptとThree.jsによる、実際に移動・戦闘できるリアルタイムWebGLゲームです。約3.2km四方の地形、約2.86km四方の移動範囲、遠景山脈を持ちます。画風は精細な部品造形と自然光を重視したスタイライズド3D。実写品質のAAAゲーム、無限世界、実車・実機シミュレーターではありません。

## 今回実装した機能
### 車：WAYFARER GT
- 草原を実際に走行できる全輪駆動風の探索車
- 面取りした車体、金属塗装・クリアコート、窓、座席、ハンドル、ドアハンドル、ミラー、ルーフラック、荷物
- タイヤの溝、合金ホイールのスポーク、ブレーキ、グリル、前後ライト、車体バッジ
- 加速、惰性減速、後退、操舵、ブースト、回転する車輪、地形に合わせた車体姿勢
- 速度計と追従カメラ。走行中は降車不可
- 車両で敵に接触すると速度に応じたダメージ

### 飛行機：KESTREL S-2
- 曲線胴体、主翼・尾翼、コックピット、キャノピー、座席・計器、支柱、脚・タイヤ、機体マーキング、航法灯
- 回転するプロペラ、加速、旋回、バンク、離陸・上昇・降下・着陸
- 速度・対地高度表示。飛行中・高速走行中は降機不可
- 高度は地面からの距離を基準とするアーケード方式。最大対地高度360m

### 戦闘と敵
- 初期配置：ゴブリン6体、人間のクリーチャーズ8人
- ゴブリン：緑の肌、長い耳、牙、鎧、斧。体力65
- クリーチャーズ：人間の肌、フード・マスク、赤い帯、剣。体力100
- 巡回、接近時の追跡、攻撃予備動作、近接ダメージ、歩行・武器アニメーション
- クリーチャーズは8方向の包囲目標と個体間分離で集団襲撃
- プレイヤー体力100、剣による近接攻撃、最寄りの敵を狙う可視光弾と連続線分による命中判定
- 回避と短時間の無敵、回復薬3個（1個55回復）、被弾演出、敵HP、討伐数
- 敗北画面と拠点復帰。復帰時はHPと薬を補充し、近い襲撃隊を拠点から離して8秒間保護
- 血液・切断などの残酷表現なし

### ボスイベント：嵐喰らい、グロム
- 巨大な角・装甲・発光コアを持つ敵。体力900
- 登場時に雷雨を開始し、専用の体力バーを表示
- 地形に沿う赤い範囲予兆 → 範囲攻撃。範囲外への移動、タイミングを合わせた回避・ジャンプが有効
- 半分以下のHPで第2形態：追跡速度、攻撃頻度、範囲と威力が上昇
- 討伐表示、勝利回数の保存、回復薬の補充
- 石環に接近するか、イベント画面から開始。生存中の重複召喚を防止

### 天候・ワールドイベント
- 晴れ / 雨 / 雷雨 / 濃霧
- 空シェーダー・光量・霧・草の風揺れ・地表の濡れ感が天候に連動
- 最大3,500本の雨線、稲妻と一時的な環境照明
- 天候は約110秒のゲーム時間ごとに自動変化。自動変化をオフにして手動選択も可能
- 初回約105秒、その後約170秒ごとにクリーチャーズの襲撃を試行（高空飛行中は見送り、同種の生存数上限あり）
- 右上の雷アイコンから車・飛行機の近傍再配置、天候選択、襲撃、ボスイベントを開始
- 設定やイベント画面を開いている間は、プレイヤー移動・敵AI・イベント時間を停止

### すぐに試す
1. スマホを横向きにし、開始地点の左前方の車・右前方の飛行機に近づきます。
2. 「乗る」を押します。離れていたら雷アイコンから乗り物を近くに配置できます。
3. 飛行機は、スティックを上へ倒して加速しながら「上昇」を押して離陸します。
4. 雷アイコン → クリーチャーズ / ゴブリン / ボスでイベントを開始できます。
5. 「攻撃」で反撃し、「回避」「ジャンプ」で攻撃を避けてください。

## データモデル・保存サービス
バックエンド、認証、外部API、Table API、データベースは使用していません。ブラウザーのlocalStorageのみです。

### 元の探索セーブ
キー：`verdant-wilds-v1`
```json
{"x":0,"z":62,"discovered":["tower","lake","stones"]}
```
- X/Z位置と発見済みの記憶。約8秒のゲーム更新ごと・発見時・pagehide時に保存
- `tower`：風渡りの古塔（-28, -178 / 発見半径14）
- `lake`：空映しの湖（158, -139 / 半径19）
- `stones`：はじまりの石環（-258, -346 / 半径17）

### 拡張セーブ
キー：`verdant-wildfront-v2`
```json
{"kills":0,"bossWins":0}
```
- 討伐数・ボス勝利数。撃破時・復帰時・pagehide時に保存
- 既存の探索セーブとは別なので、以前の記憶を維持
- HP・薬・天候・乗り物位置・敵の現在状態・各設定はセッション内のみ
- 再読み込みは徒歩・全回復で再開し、乗り物を近傍へ配置
- ブラウザーと公開ドメインごとに独立。クラウド同期なし
- 保存不能でもゲームは継続。selftestモードでは既存セーブを変更しない

### 実行中のモデル
- 乗り物：type / group / heading / speed / lift
- 敵：type / position / home / hp / maxHP / phase / aggro / attackTimer / windup / dead
- 天候：type / target / intensity / age / auto / flash
- 光弾：position / direction / speed / damage / life
- `window.verdantWorld.getState()` と `.expansion.getState()` で診断情報を参照可能
- 状態を直接配置するテスト用hookはselftestモードのみ

## 検証結果
- 拡張40項目すべてPASS：車の乗降・加速・停止、飛行機の離着陸と空中降機禁止、ゴブリン追跡と命中、HP・薬・回避無敵、ボス第2形態・討伐、8人の襲撃、天候実状態の遷移、ポーズ、敗北・安全な再起、セーブ保護
- 元の14項目も再実行で全項目PASSをログ確認。ただしソフトウェアWebGL環境では取得全体が約139秒となり、ツールの完了セレクター待機120秒はタイムアウト。ゲームのassertion失敗ではありません
- Playwright実描画：通常スマホ390×844、ボス戦PC1280×800、修正後のボス戦スマホ390×844を確認
- スマホで探索案内・回転案内・HP・ミニマップ・6操作ボタンの重大な重なりなし。ボス戦時の上部HP表示も確認
- 地形用シェーダーのGLSL予約語によるコンパイル不具合を修正し、修正後の実描画・拡張テストでは同エラーなし
- Three.js旧形式の非推奨警告、検証環境のソフトウェアWebGL / GPU ReadPixels警告は残る
- PC通常画面の一部追加スクリーンショット取得では、検証環境のGPU読み取りがタイムアウト。ボス状態のPC実描画およびスマホ両状態は取得成功
- スマホ横画面実機のFPS、同時マルチタッチの触感、iOSの全画面対応、環境音の聴感は未検証
