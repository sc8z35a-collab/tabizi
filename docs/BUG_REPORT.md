## 調査したが除外した項目（誤検知・未確定）
- **FLAGSHIPのMSAA深度テクスチャが解決されない疑い**：Three r158 のソースではドライバー依存。SwiftShaderで光芒の強度を3倍にしても輝度差が出なかったが、readPixels のタイミングが保証できないため**未確定**として除外（実機での確認を推奨）。
- **開始ゲートの裏でFLAGSHIPが全力描画する疑い**：実測でゲート表示中の postfx の frames が 3 のまま増えず、**否定**。
- コンパスの左右ラベル、`placeVehicle` の左右配置、車のロールの符号、threat-indicator の角度、`safeEnemyPoint` の楕円補正、撃破時の `terrainPose`、薬ボタン連打、J キー離しのポーズ判定、2Fの扉、降船時の湖判定、`KeyV/KeyP` の入力欄判定、ダイアログ外クリックでの閉じる判定：いずれもコードを追った結果、**正しく動作**。
